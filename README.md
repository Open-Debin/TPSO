# TPSO: Training-Free Diverse Image Generation via Semantic Prompt Embedding Optimizatio

This repository contains the official implementation of **TPSO**, a training-free method for improving diversity in diffusion-based image generation while preserving semantic fidelity.

## 🔧 Status
🚧 Code release is in progress.  
The full implementation will be made available soon.

## 📌 Highlights
- Training-free and model-agnostic
- Enhances diversity via token-level offset optimization
- Preserves semantic fidelity with prompt-level constraints
- Minimal inference overhead
